# Four preseason games: implementation checklist

This is an internal routing aid, not a coach-facing page and not permission to play a game. Four triplets, four event identities and four distinct game outputs are required.

| Game | 2015 historic appointment | New workflow prerequisites | Next required transition |
|---|---|---|---|
| 1 | Aug 14: Pittsburgh at Jacksonville, 7:30 p.m. ET | Season opened, training camp started, current 2015 contract/health/roster owners, eligible opponent roster, Stone's signed-off game-one plan | Close and record game one; update camp/battles and injuries; no automatic role award |
| 2 | Aug 22: Jacksonville at NY Giants, 7:30 p.m. ET | Actual post-game-one observations and changes, no real-life scores, new game-two plan/rotation | Close game two; update injuries, intended camp work and forthcoming 75 discussion |
| 3 | Aug 28: Detroit at Jacksonville, 8 p.m. ET | Post-game-two actual eligibility, player comparisons, current defensive communicator and real opponent information gate | Close game three; **pause before Sep 1 at 4 p.m. ET** for Caldwell's 75 reduction if not compliant |
| 4 | Sep 3: Jacksonville at Washington Redskins, 7:30 p.m. ET | Sept 1 roster to 75 properly resolved; updated actual 2015 eligible player list; Stone's fourth plan and late competition priorities | Close game four; carry findings to 53 cutdown before Sep 5 at 4 p.m. ET |

## Freeze checklist (repeat for each game)

- [ ] Fixture venue/kickoff and in-world announcement date verified; team identity uses 2015 naming.
- [ ] Staff and active playbook are from the actual current year, not assumed 2014 carry-forward individuals after unplayed events.
- [ ] Controlled player list, medical clearance/restrictions and transaction dates checked for the game's day.
- [ ] One current issued briefing with preserved earlier revisions; genuine action inserts only.
- [ ] One Stone plan accepted, natural words preserved and any change to standing instructions explicit.
- [ ] Lineups, replacement roles and rotation compiled legally; no forced exact snaps/targets.
- [ ] Season/game release confirmed, including 2015 try rules and all private service input gates.
- [ ] Original game package frozen once; an unrelated event cannot mutate it.

## Closure checklist (repeat for each game)

- [ ] Exactly one completed exhibition event, result/boxscore/rotation reconciled.
- [ ] E2 pauses answered only by Stone or an applicable valid standing direction.
- [ ] Preseason stats separate from regular/postseason counts and awards.
- [ ] Report contains football narrative, unit/role assessments supported by game data and complete boxscore last.
- [ ] Medical incidents reside at medical owners; no unrecorded return-to-play assumption.
- [ ] Each separately completed trade, signing, rejected offer, injury-list transaction or hiring pursuit has its own dated output in the correct department; game report links only.
- [ ] Position-battle questions remain open until actual Stone decisions; Caldwell cuts are independent.
- [ ] Score, outcomes, current-year roster and frozen game package remain immutable when the next game opens.
