# Alex Stone Offensive Playbook

## 2016-2017 Evolution II: Structure and Conflict

> **Team-neutral evolution manual** | Version 2.0 | Primary play-caller: Alex Stone  
> **System sentence:** Same people can change the picture. The same picture can change the answer.

This document is the second canonical evolution of Stone's offense. It is an evolution manual, not a replacement for the 2013 Iteration I book. Unless this document explicitly changes a rule, term, concept, protection, personnel relationship, or operating procedure, the Iteration I rule remains in force.

The 2014-2015 seasons are treated as refinement years inside Iteration I. Stone does not rewrite the system merely because a season ends. Iteration II begins when enough accumulated changes affect how the offense is taught, called, and generated by the simulation.

# 1. ITERATION II IDENTITY AND CHANGE RULES

Iteration I established the language. Iteration II increases the number of problems the defense must solve without increasing the amount of unrelated football the offense must memorize.

The 2013 system used personnel and formation multiplicity to change the defensive picture. By 2016, Stone wants the offense to do more than arrive in different formations. The offense now deliberately repeats the same starting pictures while changing what the picture means. The formation itself becomes part of the sequencing plan.

The physical run game remains intact. Stone does not respond to a more spread league by becoming a shotgun-only coordinator. Instead, he uses the league's increasing nickel and light-box structure as another reason to keep Power, Counter, Duo, Inside Zone, Outside Zone, and under-center play-action alive.

## 1.1 The Eight Evolution Laws

1. **The 2013 language survives unless a new rule is necessary.** Do not rename a concept merely because the presentation changed.
2. **Same people, more jobs.** A second tight end, fullback, or second runner must be able to create a space presentation without forcing a substitution.
3. **Same picture, different stress.** Repeated formations should carry run, dropback, screen, play-action, and conflict answers.
4. **Motion may create the problem.** In Iteration I, motion was often diagnostic. In Iteration II, it is also used to move the force player, widen the box, change the fit, and alter route leverage.
5. **The run action is an offensive family, not one play.** Inside, Outside, Power, Counter, and Split actions can lead to the run, ACCESS throw, READ throw, screen, boot, or shot.
6. **Use post-snap reads selectively.** A READ package exists because one defender cannot be right against both parts of the call. It is not permission to attach a throw to every run.
7. **Pullers create geometry.** Guards and tackles do more than lead a runner. Pull action can change the fit, create false keys, widen support, and set up complements.
8. **The weekly offense gets smaller as the master offense gets deeper.** New material must make an existing family harder to defend. It does not earn game-day volume simply because it was installed.

## 1.2 What Does Not Change

The following Iteration I principles remain canonical:

- Concept before formation.
- Personnel changes the matchup; formation changes the picture.
- Run downhill before running sideways.
- Take the free five when leverage gives it.
- Shots need a reason.
- Rotation changes playing time, not automatically touch share.
- A hot player can override the planned rotation.
- Personnel portability is a weapon, not a quota.
- Stone calls the offense by sequence: Show -> Stress -> Punish.
- The quarterback is a distributor and problem-solver first.
- The extra offensive lineman is a package, not a run tell.

## 1.3 What Changes Enough to Define a New Iteration

| **Area**               | **Iteration I**                                                | **Iteration II**                                                                                       |
|------------------------|----------------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| Personnel multiplicity | Many groupings with broad concept portability.                 | Fewer obvious tells inside each grouping; formal body-type variants inside 12, 20, and 21.             |
| Motion                 | Diagnostic, leverage, and occasional sweep threat.             | Diagnostic plus structural. Jet/Zip action becomes a repeatable run and pass constraint.               |
| Packaged plays         | Primarily pre-snap ACCESS with a small post-snap component.    | ACCESS remains; READ becomes a separate, limited post-snap conflict family.                            |
| Run game               | Power/Counter/Inside/Outside foundation. Duo and Split weekly. | Duo and Split rise. GT and tackle-pull work expand. Jet action is paired with core runs.               |
| Pass game              | Broad concept library with core portability.                   | More compressed releases, switch rules, back/TE movement, and repeated concepts from the same shell.   |
| Play-action            | Paired with real runs and used for shots.                      | Higher first/second-down priority; more of the explosive plan comes from repeated run pictures.        |
| Tempo                  | ROTATE, HOLD, PRESS.                                           | Same commands. HOLD/PRESS become more valuable because more personnel can morph without substituting.  |
| Offensive line         | Multiple gap/zone techniques and 6OL package.                  | Puller menu expands; tackle-pull package formalized; 6OL can transform presentation more aggressively. |

## 1.4 Human-System Rule

Iteration II is not perfectly optimized. Stone keeps some material that later versions may cut. A few 2016 ideas shrink in 2017. Some calls remain opponent-specific despite working once. The offense is allowed to develop preferences and dead ends.

The simulation must not assume that every new concept becomes permanent merely because it appears in this document.

# 2. 2016 INSTALL AND 2017 REFINEMENT

Iteration II covers two seasons because the offense changes in stages.

## 2.1 2016: Install the Structure

The 2016 rewrite has five priorities:

1. Make 12, 20, and 21 personnel more dangerous after the defense matches the bodies.
2. Increase the offense's ability to begin in one picture and finish in another without substituting.
3. Promote Duo and Split Zone so the run game has stronger answers to lighter nickel boxes and aggressive edges.
4. Formalize a tackle-pull family instead of treating tackle pulls as one Counter variation.
5. Add a small post-snap READ package while preserving the existing ACCESS language.

2016 remains an under-center-capable offense. The new spread tools are additions to the system, not replacements for Ace, Pro, I, Wing, Power, Counter, and play-action.

## 2.2 2017: Make the Structure Faster

The 2017 refinement does not add another giant concept list. It increases speed and repetition.

The 2017 priorities are:

- Use the same 11, 12, and 20 personnel groupings to reach more formations.
- Increase compressed and stack releases without giving every picture a new name.
- Use Jet and Zip action more often without necessarily handing the ball to the motion player.
- Expand READ from a two-call experiment to a four-family weekly option.
- Make 12 personnel carry enough vertical and empty football that a defense cannot automatically answer it with base personnel.
- Give the quarterback clearer one-defender post-snap rules instead of additional full-field options.
- Increase PRESS tempo only with concepts that preserve normal rules.

## 2.3 2016 to 2017 Change Table

| **Feature**  | **2016**                                  | **2017**                                                                            |
|--------------|-------------------------------------------|-------------------------------------------------------------------------------------|
| READ package | Two primary packages, opponent dependent. | Four installed families; normally two or three active each week.                    |
| Jet action   | Weekly constraint and perimeter call.     | Used as action on core runs, boots, screens, and selected dropback presentations.   |
| 12 personnel | Heavy-to-space emphasis.                  | Formal Heavy/Flex body variants; broader Empty and vertical menu.                   |
| 20 personnel | Two-runner space package.                 | More role interchangeability; either runner can become R or F in selected families. |
| Duo          | Strong weekly run.                        | Core run.                                                                           |
| Split Zone   | Strong weekly run.                        | Core or top weekly run depending opponent.                                          |
| DART         | New weekly tackle-pull run.               | Retained only when tackle mobility and opponent front justify it.                   |
| Orbit        | Experimented with as a constraint.        | Kept low volume. Timing cost prevents promotion.                                    |
| PRESS        | 20-25 call core from Iteration I.         | Roughly 25-35 calls can be carried when quarterback mastery allows.                 |

# 3. PERSONNEL ARCHITECTURE Evolution II

The league is becoming increasingly concentrated in 11 personnel. Stone does not ignore that reality. His 11-personnel package remains the largest single grouping. His distinction is that he refuses to let the roster become structurally dependent on it.

The offense still wants enough 12, 20, and 21 that defenses must practice for those bodies. The difference from 2013 is that those groupings now carry more spread and pass responsibility.

Percentages are planning centers, not quotas.

## 3.1 Planning Centers

| **Personnel** | **2013 Center** | **2016 Center** | **2017 Center** | **Iteration II Function**                                                                                      |
|---------------|-----------------|-----------------|-----------------|----------------------------------------------------------------------------------------------------------------|
| 11            | 40%             | 38%             | 40%             | Largest grouping. Full run/pass menu, motion, Empty conversion, READ package.                                  |
| 12            | 22%             | 24%             | 24%             | Primary mismatch grouping. Heavy or Flex bodies can run the same base concepts.                                |
| 21            | 13%             | 11%             | 9%              | Under-center power, fullback movement, play-action, split-to-space change-up.                                  |
| 20            | 7%              | 9%              | 10%             | Two-tailback space package. Either back may become slot/F; both are legitimate runners.                        |
| 10            | 8%              | 8%              | 9%              | Pressure, two-minute, Empty, wide spacing. Still not the identity.                                             |
| 13            | 6%              | 5%              | 4%              | Heavy tendency breaker, 6OL cousin, play-action and leak package.                                              |
| 22            | 4%              | 3%              | 2%              | Short yardage, goal line, four-minute, selected play-action.                                                   |
| 00            | Rare            | 2%              | 2%              | True five-WR change-up only when roster justifies it. Stone normally prefers Empty from run-capable personnel. |

6OL is an overlay and is not counted as a separate percentage above.

## 3.2 Body-Type Variants

Body-type variants are sideline/personnel-board terms. They are not added to normal huddle calls.

| **Variant** | **Meaning**                                                                      | **Why It Exists**                                                                            |
|-------------|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------|
| 12 HEAVY    | Two tight ends who can both function attached and block a real edge.             | Force heavier defensive fit, then shift one body into route space.                           |
| 12 FLEX     | At least one tight end is a credible detached receiver.                          | Keep the full run menu while creating 3x1, Empty, Choice, Vert, and READ matchups.           |
| 21 MOVE     | F can lead/insert but also align wing, slot, or motion across formation.         | Prevent 21 from declaring I-formation football.                                              |
| 20 TWIN     | Two true runners rather than a runner/fullback pairing.                          | Put two legitimate ball carriers on the field without requiring both to be in the backfield. |
| 13 PASS     | Three-TE grouping with at least one player capable of flex/route responsibility. | Punish goal-line/base defensive matching with a pass-capable heavy package.                  |

The variant does not change the concept word. Trey Drive remains Trey Drive whether the H job is performed by a receiving TE, a slot receiver, or a second runner who has earned that route responsibility.

## 3.3 Running Back Room: Evolution II

The Iteration I rule is retained: two or three runners can receive legitimate playing time without a promised equal carry split.

Iteration II adds two requirements:

- At least two backs should be trained for the normal CORE run menu whenever the roster permits.
- A second back who enters the game should carry more than one category of threat: run + protection, run + route, run + screen, or run + motion job.

A third back can have a narrower package, but the staff must avoid a one-call substitution tell.

The offense may use two tailbacks together in 20 TWIN. That does not mean they share one run lane or alternate carries by rule. On one call, R may be the runner and F the motion/route/control player. On another call from the same personnel, F may return to the backfield and become the runner.

## 3.4 Tight End Room: Evolution II

The tight end room becomes more important because 12 personnel now carries two distinct threats:

1. **Heavy surface football:** Power, Counter, Duo, Outside, Split, max-protect play-action.
2. **Detached football:** Mesh, Drive, Cross, Choice, Vert, READ, Empty shifts.

The offense does not pretend every tight end can do both equally. The weekly plan maps actual players to roles. A heavy Y may be a better edge blocker; a flex Y/H may be the better route player. The concept language remains stable while ownership changes.

## 3.5 Fullback / F: Evolution II

The F position survives even as traditional fullback usage falls around the league because Stone already defined F as a role, not a permanent body type.

F may be:

- traditional fullback;
- second tailback;
- move tight end;
- occasional big receiver/H body.

The player still must earn the lead/insert work required by the weekly run plan. Calling a player F does not make him a fullback blocker.

# 4. SUBSTITUTION, ROTATION, AND TEMPO Evolution II

ROTATE, HOLD, and PRESS remain unchanged. The evolution is how often Stone can move between them without losing the call menu.

## 4.1 Rotation Still Means Playing Time, Not Touch Quotas

Stone may plan a game in which three runners all play meaningful snaps and one of them receives only a handful of carries. That is acceptable if his snaps include protection, motion, receiving, screen, or decoy responsibilities.

The simulation must not convert a playing-time philosophy into a forced box-score distribution.

## 4.2 Drive-Level Substitution Pattern

A common Iteration II sequence is:

1. ROTATE early in a drive to reveal how the defense matches 12/20/21.
2. Once a favorable defensive body group appears, HOLD.
3. Change formation with Shift/Trade/Zip rather than substituting.
4. If the defense remains in the desired package and the offense owns the communication, PRESS.
5. Return to ROTATE when the matchup disappears, the offense needs a specialist, or player fatigue matters.

The sequence is not mandatory. It is a play-calling option.

## 4.3 PRESS Menu Expansion

Iteration I normally carried roughly 20-25 PRESS calls. By 2017 a veteran quarterback may carry 25-35 because the concepts do not require a second language.

The expanded PRESS menu can include:

- Inside Zone / Split Zone;
- Duo;
- Draw;
- Stick / Spacing / Slant-Flat;
- Mesh / Drive / Shallow;
- Dagger;
- Four Verticals;
- Smoke / Bubble;
- RB Slow / Slip;
- one or two READ calls;
- one Alert shot.

Power and Counter can be included in PRESS only if the line can communicate the front rule quickly. The offense does not rush into a bad gap call merely to maintain tempo.

# 5. FORMATION ARCHITECTURE Evolution II

Iteration II does not add dozens of formation names. It increases the number of useful transformations inside the existing families.

## 5.1 New Formation Emphases

| **Existing Family** | **Iteration II Emphasis**                                                                               |
|---------------------|---------------------------------------------------------------------------------------------------------|
| Doubles             | More Tight/Stack presentations, back flex/return, READ and quick-game pairings.                         |
| Trey                | Becomes one of the best all-purpose shells: Power weak, Inside, Drive, Cross, Dagger, READ, Jet action. |
| Trips               | More compressed and stack releases; used for conflict counts and quick perimeter access.                |
| Bunch               | Man answer remains; now paired more deliberately with runs from the same personnel.                     |
| Ace                 | Remains central under center. Duo, Outside, Power, Post-Cross, Mills, and play-action remain available. |
| Wing                | Grows because Split, Counter, Jet action, Boot, and leak can share the same surface.                    |
| Pro / I             | Retained despite league spread. Used for run/play-action illusion and to force downhill fits.           |
| Empty               | More often reached by shift from 11, 12, and 20 rather than true 00 substitution.                       |
| Heavy / Unbalanced  | More transformation after defensive matching; not just short-yardage structure.                         |

## 5.2 Compression Rule

TIGHT and Stack modifiers rise in weekly usage because compressed releases create:

- more space outside for overs, corners, and out-breakers;
- better crack angles in the perimeter run game;
- natural traffic against man coverage;
- easier disguise between run-support and route jobs.

Compression is not automatic. Wide splits still matter when Stone wants to expand the box or isolate a corner.

## 5.3 Same-Picture Rule

The weekly game plan now identifies two or three pictures from which Stone wants at least four different categories of call.

Example, 12 Wing Right:

- Split Zone L;
- Counter R;
- Boot Flood R;
- Mesh with Y/H crossers;
- Split Leak;
- Jet action Inside;
- READ Slant if installed.

If a formation carries only one answer, it becomes a tendency and either receives complements or loses volume.

## 5.4 Empty Return

Empty is no longer only a final formation. A back can align detached, force the defense to declare, then RETURN to the backfield before the snap.

The return may produce:

- Inside Zone;
- Duo;
- Draw;
- protection help;
- boot action on the next call from the same initial picture.

The offense uses this to gather information, not to create needless motion.

# 6. SHIFT AND MOTION SYSTEM Evolution II

The motion vocabulary remains short: ZIP, JET, RETURN, ORBIT, TRADE, SHIFT.

The difference is that motion is now integrated into the blocking and route families instead of sitting beside them as a separate library.

## 6.1 Motion Jobs

Every motion must do at least one of the following:

1. identify a coverage relationship;
2. change the formation strength;
3. change the fit or force player;
4. create a leverage throw;
5. add a perimeter run threat;
6. create false flow for a run or screen;
7. improve release access for a receiver/TE.

A motion that does none of those is removed.

## 6.2 JET Promotion

JET was a change-up in Iteration I. It becomes a weekly family in 2016 and a common action in 2017.

JET can produce:

- Jet Sweep;
- Inside Zone with Jet action;
- Split Zone with Jet action;
- Duo with Jet action;
- Power away from motion;
- Boot/Flood after Jet action;
- Bubble/Smoke or fake screen;
- occasional reverse/change-up.

The offense does not need to hand the ball to the Jet player repeatedly. The purpose is to force the edge and second level to account for width.

## 6.3 ZIP Evolution

ZIP remains a fast crossing motion, but it is now attached more frequently to Bunch, Stack, and Tight formations.

Typical ZIP jobs:

- create a free release for Mesh/Shallow;
- move the apex defender before Inside/READ;
- reveal man travel;
- become a flat player after motion;
- enter crack position for Toss/Pin-Pull.

## 6.4 RETURN

RETURN becomes a specific answer to defenses that over-rotate or over-bump to initial motion.

Stone may show Zip across, then Return the player to his original side and snap after the defense has declared its exchange rule.

The call still must fit the cadence. RETURN is not used when the motion would consume too much play clock or create procedural risk.

## 6.5 ORBIT Is Not Promoted

Stone experiments with more ORBIT in 2016 because it can create screen and perimeter leverage. It remains low volume in 2017.

Reason: the deeper path can distort timing, reduce downhill urgency, and become decorative if overused. ORBIT remains an opponent-specific tool rather than a system identity.

## 6.6 Motion-at-Snap Guardrail

JET and selected ZIP calls can be snapped with the player in motion. TRADE, SHIFT, and most RETURN calls require the player to reset as defined by the call.

Iteration II does not turn constant motion-at-snap into the base offense. That belongs to a later evolutionary problem if Stone reaches it.

# 7. QUARTERBACK OPERATING SYSTEM Evolution II

The quarterback retains the Iteration I Pre-Snap Five: point, box, shell, pressure, leverage.

Iteration II adds a cleaner distinction between pre-snap access and post-snap conflict.

## 7.1 ACCESS vs READ

**ACCESS** is normally decided before the snap from numbers or leverage.

**READ** is decided after the snap from the first action of one designated conflict defender.

The quarterback is never asked to turn a READ call into a full-field progression before handing the ball off. If the conflict is not immediate, give the run.

## 7.2 READ Decision Rule

The quarterback uses three words internally:

1. **Key**: identify the one conflict defender.
2. **Step**: read his first committed movement.
3. **Give/Throw**: make the decision on time.

A late RPO decision is graded as a quarterback error even when the result is positive.

## 7.3 Mobility Expansion

The quarterback's legs gain slightly more responsibility:

- boots and nakeds increase;
- selective zone-read keeper remains available;
- a READ call may leave an edge defender unblocked;
- scramble conversions remain encouraged after structure breaks.

Stone still does not require a quarterback rushing workload. If the quarterback is an exceptional runner, a roster-specific package may expand, but the master Iteration II offense remains pocket-oriented.

## 7.4 Kill and Alert Expansion

The number of KILL pairs increases because the offense now has more same-picture answers.

Examples:

- Ace Duo KILL Boot Flood versus overloaded run fit.
- Trey Inside KILL Stick versus unfavorable box.
- Wing Outside KILL Counter versus over-shifted edge.

ALERT remains a shot permission, not an audible system.

## 7.5 Empty Protection Identification

The quarterback is expected to identify five immediate rush threats and the potential free sixth defender. Empty is used to expose pressure rules, not to pretend the offense can block everyone.

If the defense presents a pressure picture the weekly Empty plan cannot solve, the quarterback can RESET a return motion or KILL to the installed quick answer.

# 8. PROTECTION SYSTEM Evolution II

SCAT, HALF, SOLID, BOB, MAX, TURNBACK, and NAKED remain the protection families.

Iteration II changes the number of formations from which those protections are expected to survive.

## 8.1 Protection Portability

HALF and SOLID must now function after:

- 12 personnel detaches a tight end;
- 20 personnel flexes F;
- Empty Return brings R back into the protection;
- Jet/Zip changes the perceived strength;
- a Tight/Stack modifier changes receiver location.

The protection does not reset merely because the presentation moved.

## 8.2 MUG Identification

MUG is added as a defensive identification, not a new protection.

MUG means one or more linebackers are walked into interior gaps to threaten immediate pressure.

The offense answers with existing tools:

- reset the point;
- PINCH/FAN the line when installed;
- BOB the declared threats;
- keep R in SOLID;
- replace pressure with Stick/Slant/Mesh;
- screen the pressure;
- shift back from Empty if the weekly plan requires it.

The staff should not invent a new protection every time a defense changes the mug picture.

## 8.3 Pull-Action Protection

As pullers become a larger run key, TURNBACK and play-action protections must reproduce credible guard/tackle movement without creating illegal downfield action.

The offense now grades the first two steps of play-action linemen and backs against the paired run. A shot is weakened if the defense can distinguish pass posture immediately.

## 8.4 Back Protection and Rotation

The Iteration I rule becomes stricter: a back who enters on third down or PRESS downs must be protection-clean enough that his entry does not force the offense to remove core calls.

This can reduce a player's playing time even if he is the best pure runner in the room.

# 9. RUN GAME EVOLUTION

The run game remains physically downhill. The major change is how many ways Stone can manipulate a light box or fast-flow defense without changing the base identity.

## 9.1 2017 Core Run Hierarchy

**CORE:** Power, Counter/GT, Inside Zone, Outside Zone, Duo.

**CORE/WEEKLY border:** Split Zone.

**WEEKLY:** Lead/Iso, Pin-Pull, Toss/Crack, DART, Jet Sweep.

**CHANGE-UP:** Trap, Wham, Reverse, specialty tackle/guard packages.

The weekly plan can promote or demote one level based on personnel and opponent.

## 9.2 POWER: Evolution II

Power remains the physical identity call.

New Iteration II uses:

- Power with Jet action away;
- Power from 20 TWIN with F detached or motioning;
- Power from 12 FLEX after showing spread;
- Power KILL Boot/Flood or quick access;
- Power from Tight/Stack receiver structures that force support closer to the formation.

**Expected Yardage:** 3-6, unchanged.

Stone does not convert Power into a QB-run concept merely because option football is more common.

## 9.3 COUNTER / GT: Evolution II

GT becomes a normal Counter variation rather than a rare tag.

The offense carries two main Counter structures:

- **G-H / G-Y Counter:** guard kicks/logs; H/Y wraps.
- **GT Counter:** guard handles edge rule; tackle wraps into second level.

The weekly opponent determines which one receives volume.

Jet/Zip away from Counter can widen support before the pullers arrive.

**Expected Yardage:** 4-8. The upper end rises slightly because successful pull geometry against spread boxes can create cleaner second-level lanes.

## 9.4 DUO Promotion

Duo moves from WEEKLY toward CORE because it punishes nickel fronts without requiring the back to race horizontally.

The back still reads the linebacker fit behind vertical double teams.

New uses:

- 11 Tight Duo;
- 12 Ace/Wing Duo;
- 20 TWIN Duo with F flexed or motioning;
- Jet-action Duo;
- Duo + Smoke ACCESS;
- selected Duo + POP READ in 2017.

**Expected Yardage:** 4-7.

## 9.5 SPLIT ZONE Promotion

Split becomes more important because its crossing H/Y action can:

- seal the backside edge;
- bluff/arc the edge;
- release to flat;
- leak behind flow;
- create the conflict defender for READ.

By 2017, Stone can call the same Wing picture as Split, Bluff Inside, Boot, Leak, or READ Slant.

**Expected Yardage:** 4-7.

## 9.6 INSIDE ZONE: Evolution II

Inside Zone remains the cleanest run to pair with quick access and post-snap READ.

New complements:

- Jet action;
- Return-to-backfield from Empty;
- READ Glance;
- READ Slant;
- Pop from attached/flex Y when the second-level fit is aggressive.

The line's rules remain zone rules. The quarterback's decision cannot change the line's blocking after the snap.

**Expected Yardage:** 4-6.

## 9.7 OUTSIDE ZONE: Evolution II

Outside Zone gains more formation and motion disguise but stays a one-cut run.

New complements:

- Jet action in the opposite direction;
- tight receiver crack/arc rules by weekly plan;
- Empty Return to Outside;
- faster boot/flood sequence;
- throwback screen after repeated boot flow.

**Expected Yardage:** 4-8, unchanged.

## 9.8 DART: New Tackle-Pull Family

DART is the major new run concept of Iteration II.

**Purpose:** Use a backside tackle pull to create an interior gap run from a spread or detached presentation while giving the defense a different pull key from Counter.

**Core structure:** Frontside blocks down/away from penetration according to the front. Backside tackle pulls through the declared interior lane. Back presses the frontside track and follows the tackle's leverage.

**Best personnel:** 10, 11, 12 FLEX, 20.

**Best formations:** Doubles, Trey, Tight Doubles, 20 Spread.

**Expected Yardage:** 4-7.

**Tier:** WEEKLY.

**Sample calls:** Gun Doubles Dart R; 20 Trey Dart L.

DART is not universal. If the tackle cannot pull in space or the defensive front makes the angle poor, it is removed from the weekly sheet.

## 9.9 PIN-PULL: Evolution II

Pin-Pull remains a weekly perimeter answer. The compressed receiver package improves crack/support angles.

The offense now pairs Pin-Pull with:

- Jet fake;
- Smoke ACCESS;
- quick play-action Sail;
- same-side screen look.

**Expected Yardage:** 4-8.

## 9.10 JET SWEEP Promotion

Jet Sweep moves from CHANGE-UP to WEEKLY.

The offense does not need a high carry count for Jet to matter. The motion must be credible enough that force and second-level defenders cannot ignore it.

**Expected Yardage:** 4-9.

## 9.11 Lead / Iso Reduction

Lead and Iso remain real calls, especially in 21, 22, four-minute, and short yardage. Their total master-book importance declines because Duo and Split can create downhill football from more flexible personnel.

Stone does not delete the fullback run game. He uses it more selectively.

# 10. PASS GAME EVOLUTION

The pass game adds very few new full concepts. Instead, Iteration II expands release, formation, and personnel ownership inside concepts already mastered.

## 10.1 Core Pass Hierarchy: Evolution II

**CORE:** Stick, Mesh, Drive, Y-Cross, Dagger, Four Verticals.

**CORE/WEEKLY border:** Post-Cross, Spacing, Shallow.

**WEEKLY:** Snag, Smash, Curl-Flat, Sail/Flood, Texas, Mills, Choice.

**CHANGE-UP:** Scissors, Whip/Pivot, double moves, specialty Empty calls.

Dagger is promoted because it complements the expanded run/play-action middle-field stress.

## 10.2 Compressed Release Rules

Tight and Stack alignments now carry explicit release responsibilities.

- Front player wins clean release first and avoids drifting into the second player's stem.
- Back player delays only enough to prevent collision; he cannot jog through the concept.
- Against press-man, releases can exchange who becomes the immediate clear and who becomes the in-breaker if the concept's spacing remains intact.
- Against zone, receivers must not turn a designed switch release into two players occupying the same window.

## 10.3 MESH: Evolution II

New normal variants:

- Mesh Rail with R/F on sideline rail;
- Mesh Return after ZIP/RETURN motion;
- 12 FLEX Mesh with one TE as crosser and one as sit/control;
- 20 TWIN Mesh where either back can own rail or check role.

The quarterback still reads Mesh, not four new plays.

**Expected Yardage:** 6-11.

## 10.4 DRIVE: Evolution II

Drive becomes one of Stone's best same-picture calls because it can be run from:

- 11 Trey;
- 12 Trey/Flex;
- 20 Doubles;
- 21 after F shifts to wing/slot;
- Empty conversion.

Alert Post becomes a more common tag after safeties drive the dig/shallow relationship.

**Expected Yardage:** 8-15.

## 10.5 Y-CROSS: Evolution II

Cross ownership expands. Y, H, F, or a flexed back can own the cross when personnel and skill permit.

Stone does not treat those players as identical. Route landmark and expected speed are adjusted during installation, while the quarterback's progression remains conceptually stable.

**Expected Yardage:** 9-16.

## 10.6 DAGGER Promotion

Dagger moves into CORE because the offense increasingly uses run action, access throws, and compressed formations to manipulate hook and safety depth.

New normal tags:

- Switch seam;
- Return motion;
- Alert Post;
- Max on shot down.

**Expected Yardage:** 10-19.

## 10.7 FOUR VERTICALS: Evolution II

Four Verticals becomes more coverage-specific rather than simply more frequent.

New emphasis:

- seam Choice rules versus two-high;
- switch release from compressed sets;
- back wheel as fifth vertical from 11/20 Empty;
- Y bender only when coverage structure gives the landmark.

Stone still prefers a defined leverage trigger to blind deep-ball volume.

**Expected Yardage:** 15-30+.

## 10.8 POST-CROSS Promotion

Post-Cross rises because it pairs naturally with under-center run action and can be protected with heavy personnel.

The 2016-17 offense uses it from Ace, Pro, Wing, Heavy, and selected Trey structures.

Leak remains a tag, not a new concept.

**Expected Yardage:** 15-30+.

## 10.9 CHOICE Expansion

Choice remains controlled. Stone expands it because TE/RB/slot matchups are more valuable from 12 FLEX, 20 TWIN, and Empty shifts.

The route player receives defined rules. The quarterback is not allowed to stare at Choice against bracketed leverage and ignore the rest of the concept.

**Expected Yardage:** 6-12.

## 10.10 New Route Tags

Iteration II adds only three common words:

| **Tag** | **Meaning**                                                                                        | **Primary Use**                             |
|---------|----------------------------------------------------------------------------------------------------|---------------------------------------------|
| GLANCE  | Fast skinny in-breaker behind an aggressive second-level defender, normally 6-10 yards.            | READ package, occasional quick play-action. |
| POP     | TE/H vertical pop into vacated linebacker space, normally 5-10 yards.                              | READ package and short play-action.         |
| SWITCH  | Exchange vertical/release responsibilities between two eligibles while preserving concept spacing. | Vert, Dagger, Sail, selected shots.         |

No other tag is added unless a weekly opponent creates a specific need.

# 11. PLAY-ACTION AND MOVEMENT PASS EVOLUTION

Iteration II increases the importance of play-action rather than dramatically expanding the number of named play-action calls.

## 11.1 Under-Center Football Stays

Stone does not interpret league-wide spread growth as evidence that under-center offense is obsolete.

Ace, Pro, I, and Wing remain valuable because they can create:

- harder downhill backfield tracks;
- cleaner run-action illusion;
- deeper quarterback launch points;
- strong boot relationships;
- max-protection vertical shots.

The offense may use less I-formation overall than in 2013, but the plays that survive are practiced at full detail.

## 11.2 Play-Action Families: Evolution II

| **Family**   | **Paired Run**                 | **Iteration II Change**                                            | **Expected Yardage** |
|--------------|--------------------------------|--------------------------------------------------------------------|----------------------|
| POWER PASS   | Power                          | More Post-Cross and corner-over structures; Jet fake can be added. | 15-30+               |
| COUNTER BOOT | Counter/GT                     | Pull action must match actual weekly Counter rules.                | 8-17                 |
| OUTSIDE BOOT | Outside Zone                   | Higher weekly volume; same Wing/Ace picture used for run and pass. | 8-17                 |
| SPLIT LEAK   | Split Zone                     | Promoted. Bluff/sift behavior creates delayed release.             | 10-21                |
| DUO DAGGER   | Duo                            | New normal pairing using run posture to open deep dig.             | 10-19                |
| LEAD POST    | Lead/Iso                       | Lower overall volume but retained as high-value 21/22 shot.        | 15-28                |
| JET BOOT     | Inside/Outside with Jet action | New change of flow. Motion widens edge before boot returns away.   | 8-17                 |

## 11.3 First-Down Shot Rule

Iteration II is more willing to take first-down shots when the formation/run tendency has earned the trigger.

Stone does not wait for 2nd-and-1 to call every explosive. If a safety is fitting hard on early-down Power/Outside action, the shot may come on 1st-and-10 while the defense still believes the offense is establishing the run.

## 11.4 Movement Pass Volume

Boot, Naked, and Sprint remain controlled. More movement does not mean the quarterback lives outside the pocket.

A movement pass must still have a purpose:

- punish pursuit;
- change launch point against edge rush;
- create a three-level stretch;
- use the quarterback's mobility without making him the primary runner.

# 12. ACCESS AND READ PACKAGES

This is the most important terminology change in Iteration II.

ACCESS and READ are no longer treated as the same kind of decision.

## 12.1 ACCESS Remains Pre-Snap

Core ACCESS families remain:

- Inside + Bubble;
- Inside + Stick;
- Power + Smoke;
- selected Zone + Slant when the decision is clearly leverage-based before the snap.

The quarterback decides ACCESS from numbers and leverage. If neutral, run the called run.

## 12.2 READ Is Post-Snap

READ tells the quarterback one defender is being placed in conflict after the snap.

The line executes the called run. The route is built to receive the ball immediately enough to remain legal with run blocking.

### Guardrails

- One designated read defender.
- No second post-snap coverage read before Give/Throw.
- Throw immediately on the defined window.
- If uncertain, give the run.
- Linemen do not slow their run blocks to protect a late quarterback decision.
- The weekly plan limits READ volume so normal dropback and run football remain primary.

## 12.3 2016 READ Menu

### INSIDE READ GLANCE

**Run:** Inside Zone.

**Pass:** GLANCE behind the conflict LB/overhang.

**Read:** Second-level defender responsible for fitting run and closing in-breaker.

**Expected Yardage:** Run 4-6 / Pass 6-12.

**Personnel:** 10, 11, 12 FLEX, 20.

**Primary formations:** Doubles, Trey, Trips Tight.

### SPLIT READ SLANT

**Run:** Split Zone.

**Pass:** Fast Slant/Glance into vacated inside window.

**Read:** Backside overhang/linebacker affected by split action.

**Expected Yardage:** Run 4-7 / Pass 5-10.

**Personnel:** 11, 12, selected 20.

**Primary formations:** Wing, Trey, Tight Doubles.

A normal 2016 week may carry only one of the two.

## 12.4 2017 READ Additions

### DUO READ POP

**Run:** Duo.

**Pass:** Y/H POP behind an aggressive linebacker fit.

**Read:** Second-level fit defender.

**Expected Yardage:** Run 4-7 / Pass 5-12.

**Personnel:** 11, 12.

**Primary formations:** Ace Gun, Trey, Wing.

### OUTSIDE READ BUBBLE

**Run:** Outside Zone or wide Inside variant by weekly plan.

**Pass:** Bubble/fast perimeter throw after the read player commits to fit.

**Read:** Apex/overhang responsible for run support and perimeter leverage.

**Expected Yardage:** Run 4-8 / Pass 4-9.

**Personnel:** 10, 11, 20.

**Primary formations:** Trips, Trey, Doubles with motion.

This is not automatically superior to pre-snap ACCESS Bubble. The staff chooses the form that best attacks the opponent's rules.

## 12.5 READ Does Not Pollute Every Run

The following remain normal run calls unless a weekly package explicitly changes them:

- Power;
- Counter/GT;
- DART;
- Lead/Iso;
- Pin-Pull;
- Toss/Crack;
- Trap;
- Wham.

Stone does not attach a throw merely to make the call look modern.

# 13. SCREEN AND PERIMETER GAME EVOLUTION

The screen menu stays compact, but motion creates more convincing setup pictures.

## 13.1 Screen Tier: Evolution II

**CORE:** RB Slow, Smoke/Now, Bubble.

**WEEKLY:** RB Slip, WR Tunnel/Jail, TE Delay, Middle.

**CHANGE-UP:** Throwback, fake screen shots, Orbit screen.

## 13.2 Jet/Screen Relationship

Jet action can widen or accelerate perimeter defenders before:

- RB Slow opposite motion;
- Tunnel back underneath motion;
- Smoke/Now to vacated side;
- throwback screen after Boot/Jet flow.

The motion player cannot become a blocking obstacle to the screen convoy. Timing is installed as one play.

## 13.3 Throwback Promotion

Throwback Screen rises from gadget status to a real weekly possibility against defenses that aggressively chase Boot/Jet movement.

**Expected Yardage:** 8-15.

**Tier:** WEEKLY/CHANGE-UP border.

It still requires opponent pursuit evidence. Stone will not call it merely because the diagram looks clever.

## 13.4 Perimeter Touch Rule

The offense wants a credible perimeter threat without creating a gimmick-player touch quota.

Jet players, backs, tight ends, and slots can receive perimeter touches when the leverage is useful. The call sheet does not reserve a minimum number of gadget touches for any player.

# 14. 6OL AND OFFENSIVE-LINE PACKAGE EVOLUTION

Stone's offensive-line creativity expands in two directions:

1. the sixth-lineman package becomes more transformable;
2. normal five-OL runs use guards and tackles more aggressively as moving pieces.

## 14.1 6OL Evolution Rule

Every active 6OL menu now carries four categories when personnel allows:

1. downhill run toward the extra surface;
2. run away / misdirection;
3. play-action or dropback pass;
4. structure-changing call after HOLD.

The fourth category is the main evolution.

## 14.2 Structure-Changing 6OL Calls

After the defense matches a heavy surface, Stone may HOLD and:

- shift the Y/H away from the extra tackle;
- create an isolated X backside;
- widen remaining eligibles into a 2x2-like four-eligible presentation;
- run away from the extra surface;
- use max protection with only two or three receivers out;
- release T6 only when he is legally eligible/reported and the weekly package explicitly allows it.

The offense does not use confusing eligibility as a substitute for execution. Reporting and formation legality are part of the install.

## 14.3 Sample 6OL Evolution Mini-Menu

1. Heavy Right Power R
2. Heavy Right Counter L
3. Over Left Duo L
4. Over Left Outside R
5. Nub Right Post-Cross Max
6. Heavy Right Jet Boot L
7. Over Left Hold -> Trey Drive from same personnel when eligibility permits the planned distribution
8. Wing Left Leak only when T6/Y reporting structure is clear

A normal game still carries only the calls practiced that week.

## 14.4 Puller Package: Evolution II

Stone's five-OL run game now categorizes pullers by job rather than by play name alone.

| **Puller Job** | **Typical Concepts**  | **Coaching Purpose**                                                  |
|----------------|-----------------------|-----------------------------------------------------------------------|
| Kick           | Power, Counter        | Remove/turn force defender.                                           |
| Log            | Power, Counter        | Handle wrong-arm/spill by wrapping run outside.                       |
| Wrap           | GT Counter, DART      | Enter second-level lane after down blocks.                            |
| Perimeter      | Pin-Pull, Toss        | Lead around edge with leverage.                                       |
| Influence      | play-action/change-up | Show familiar pull key without taking the ball to the expected point. |

This is how Stone's offensive-line innovation is expressed. He is not credited with inventing pulling linemen. He makes puller movement a consistent method of creating and manipulating space across personnel groups.

# 15. SITUATIONAL OFFENSE Evolution II

The situation menus keep the Iteration I structure. Several emphases change.

## 15.1 Third and Medium

Third-and-3 through third-and-6 gains more normal-down crossover.

Preferred families:

- Mesh;
- Drive;
- Stick Choice;
- Texas;
- Shallow;
- Duo/Draw against light pressure boxes;
- READ only if heavily practiced that week.

Stone does not automatically empty the backfield on third medium.

## 15.2 Red Zone

Compressed formations and 12 FLEX grow in value.

New red-zone priorities:

- Snag/Choice from Tight/Bunch;
- Mesh with short rail;
- Duo/Power from spread 12;
- Split Leak;
- Pop only if the defender conflict is clean;
- Jet action to widen edge before Power/Boot.

The READ package shrinks near the goal line unless route/run spacing is specifically practiced for the reduced field.

## 15.3 Two Minute

11, 10, and 20 remain the normal two-minute groups. 12 FLEX is now allowed as a primary two-minute group when the tight ends can operate detached without slowing alignment.

PRESS mechanics remain more important than personnel label.

## 15.4 Four Minute

The 2013 principle survives: first downs matter more than proving toughness.

Iteration II adds more Duo, Counter, and play-action from 12/21. If the defense adds bodies to stop the run, Stone is willing to throw from heavy personnel rather than substituting into a predictable passing package.

# 18. INSTALLATION AND PRACTICE CHANGES

Iteration II should not be installed as a second full playbook. New material is layered onto existing mastery.

## 18.1 Five-Install Evolution Plan

| **Install** | **New Material**                                                 | **Required Carryover**                          |
|-------------|------------------------------------------------------------------|-------------------------------------------------|
| 1           | 12 HEAVY/FLEX and 20 TWIN role maps; Tight/Stack release review  | Power, Inside, Stick, Mesh, protection language |
| 2           | Duo promotion; GT Counter; DART introduction                     | Counter rules, puller communication, front IDs  |
| 3           | Jet action on core runs; Zip/Return sequencing                   | motion timing, Toss/Jet ball security           |
| 4           | ACCESS vs READ distinction; Inside Read Glance; Split Read Slant | Inside/Split blocking, QB leverage rules        |
| 5           | Same-picture series day; 6OL evolution; PRESS expansion                 | HOLD/PRESS, play-action, screen, shot setup     |

2017 adds Duo Read Pop and Outside Read Bubble only after the offense proves it can execute the first two READ packages without late decisions or illegal downfield problems.

## 18.2 Practice Period Changes

### Conflict Period

A short daily period works the read defender at game speed. The defense is instructed to give different first-step reactions. The quarterback must Give/Throw on schedule.

### Same-Picture Period

Offense lines up in one formation and executes three or four different categories without changing the initial picture. The goal is not trickery; it is eliminating formation-specific tells.

### Motion Fit Period

Run game reps Jet/Zip action against changing force/fit rules. The motion player sometimes receives the ball and sometimes does not.

### Puller Period

Guards/tackles work kick, log, wrap, and perimeter landmarks. The drill grades path and leverage, not merely contact.

## 18.3 Mastery Tests: Evolution II

### Quarterback

- Can distinguish ACCESS from READ without hesitation.
- Can identify the one READ defender before cadence.
- Gives the ball when the read is muddy.
- Can execute Empty Return protection checks.
- Can run expanded PRESS menu without creating new terminology.

### Running Backs

- At least two backs know core run tracks and normal protection menu.
- 20 TWIN backs can align as R/F/slot only for practiced jobs.
- Motion/return timing does not reveal which back is the runner.
- Rotation does not create substitution confusion.

### Tight Ends / F

- 12 FLEX players can detach without changing concept language.
- 12 HEAVY players can execute edge and double-team responsibilities.
- H/Y can sift, bluff, arc, and leak from Split family.
- Route ownership changes are understood without new play names.

### Offensive Line

- Can handle GT and DART pulls without losing base Power/Counter rules.
- Can distinguish run-blocking READ calls from normal pass protection.
- Understands legal downfield timing on READ throws.
- Can sell pull action on play-action without crossing legal limits.

# 19. SIMULATION DIRECTIVES FOR 2016-2017

These rules tell the simulation how Iteration II should behave. They are not season-stat quotas.

## 19.1 Evolution Selection

- 2013-2015: Iteration I rules.
- 2016: Iteration II with limited READ menu and newly installed DART/Jet structure.
- 2017: Iteration II refined, with broader same-personnel transformation and deeper READ/Jet sequencing.

## 19.2 Call Generation Priority

Generate calls in this order:

1. Weekly active menu.
2. Game-state/situation.
3. Personnel currently on field.
4. Defensive structure and documented reaction.
5. Series relationship to previous calls.
6. Player availability/skill.
7. Change-up only when its trigger exists.

Do not randomly select from the master concept list.

## 19.3 Personnel Rules

- 11 remains the largest grouping but should not dominate Stone to the league-average degree every week.
- 12 receives substantial pass volume, especially in 2017.
- 20 is a real package, not a trick formation. Either runner may be R or F on installed calls.
- 21 declines somewhat but remains strategically important.
- Empty should often be generated by shifting 11/12/20 rather than substituting true 00.
- Rotation determines snaps and roles, not automatic carry distribution.

## 19.4 Motion Rules

- Motion frequency rises from Iteration I, especially Jet/Zip.
- The motion player should not receive the ball often enough for the simulation to equate motion with touch.
- JET action should appear on normal runs and play-action, not only Jet Sweep.
- ORBIT remains low frequency.
- Do not simulate later-era constant short motion-at-snap behavior.

## 19.5 READ Rules

- READ can be generated only if the weekly package is active.
- READ requires a designated conflict defender.
- A muddy read defaults to Give.
- A late throw carries elevated penalty/error risk because of ineligible-downfield timing and crowded windows.
- The quarterback's running ability affects keeper/change-up calls, but does not transform every READ into a triple option.

## 19.6 Run Distribution Rules

Stone is willing to call the same successful run repeatedly. The AI must not force diversity merely because another concept exists.

At the same time, repeated defensive overplay increases the probability of the paired complement:

- Power success -> Counter / Power Pass;
- Outside pursuit -> Boot / cutback / Throwback;
- Inside fit -> READ/Access or Dagger play-action;
- Jet overreaction -> run away / boot opposite.

## 19.7 Player Rotation Rules

- Two or three runners may receive meaningful playing time.
- One runner can still dominate touches if performance/game state warrants it.
- A back can have significant snaps with few carries because of route/protection/motion work.
- Do not remove a productive back solely to preserve planned rotation.
- Do not enter an unqualified player solely because he is fresh.

## 19.8 Expected Yardage Rules

Expected Yardage remains a concept band. Player ability, defensive leverage, game state, field position, and execution modify actual output.

READ calls use separate run/pass bands because the quarterback decision changes which component is executed.

## 19.9 2017 Boundaries

Do not import the following into Iteration II:

- universal motion-at-snap;
- Miami-style cheat motion;
- full-time gun/pistol run game;
- extensive QB designed-run volume as the default;
- every run carrying an RPO;
- 2021+ two-high-specific offensive counters as a defined system response;
- 2023-24 motion rates or condensed-formation obsession;
- later coordinator branches or hybrid identities that have not occurred in the simulation.

# APPENDIX C. HISTORICAL GROUNDING NOTES

These notes define the historical rails used to keep Evolution II plausible. They are not claims that Stone copied any one real coach or playbook.

1. **The league was increasingly an 11-personnel league.** PFF's later personnel study reported league-average 11-personnel usage at 59 percent in 2016 and 58 percent in 2017, while 21 personnel sat at 7-8 percent. Stone therefore becomes more unusual, not less, by continuing to carry meaningful 12/20/21 volume while keeping 11 as his largest grouping.
2. **Traditional fullback usage was falling, while option mechanics were spreading.** PFF's 2016 preseason data review noted a major decade-long decline in fullback usage and reported option mechanics on more than ten percent of 2015 handoffs. Evolution II therefore keeps F as a movable role rather than a fixed I-back and permits a controlled READ expansion without turning Stone into a college-option offense.
3. **Physical under-center play-action remained highly effective.** NFL.com retrospective analysis of the 2016 Falcons emphasized their I-formation run/play-action relationship and the explosive passing opportunities created by believable run action. That supports Stone retaining Ace/Pro/I and increasing play-action rather than abandoning under-center football.
4. **2017 offenses demonstrated that multiplicity can come from both personnel diversity and repeated core structures.** NFL.com analysis of the Rams and Eagles described the Rams running many different plays from familiar 11/shotgun/ace structures, while the Eagles used heavy and fast versions of their main personnel groups and moved pieces around while repeating the core offense. Stone's Iteration II formalizes both ideas through body variants and same-picture series architecture.
5. **RPOs were becoming a visible NFL tool by 2017.** NFL.com film analysis of the 2017 Eagles described run-pass options as a major part of contemporary discussion and showed zone-run action placing a defender in post-snap conflict. Stone already had pre-snap ACCESS in 2013; Iteration II therefore adds READ as a limited post-snap category rather than pretending he discovers the idea from nowhere in 2017.
6. **12 personnel could be run/pass balanced and vertically dangerous.** NFL.com coverage of Green Bay's 2017 tight-end additions explicitly discussed 12 personnel as a grouping that could run in either direction and carry the vertical passing game. Stone's 12 FLEX/HEAVY split is a fictional implementation of the broader strategic reality, not a copy of Green Bay terminology.

# APPENDIX D. MATERIAL REDUCED, REJECTED, OR DEFERRED

A system feels human partly because it does not keep every idea.

## D.1 Reduced After 2016 Testing

**Orbit package:** useful for a few screens and edge manipulations, but too easy to make decorative. Retained as change-up.

**True 00 expansion:** Stone tests more true five-WR structure but prefers Empty from 11/12/20 because it preserves a credible return-to-run threat and reduces specialist substitutions.

**DART as universal answer:** DART works only with a tackle who can pull and with fronts that give the correct angle. It remains weekly, not CORE.

**READ everywhere:** rejected. The quarterback and line execute better when post-snap conflict calls are a defined family rather than an attachment to every run.

## D.2 Deferred to Later Iterations

- high-volume motion-at-snap;
- more advanced condensed-formation sequencing;
- full answer package to split-safety/light-box structures as a league-wide defensive identity;
- broader quarterback-run menu;
- later forms of return/fast motion designed specifically to win leverage immediately before the snap;
- any offensive coordinator branch that changes Stone's identity after the simulation hires a historically distinct OC.

## D.3 Canonical Rule Going Forward

Iteration III evolves Iteration II. It may remove or reshape material in this book. It does not have to preserve a 2016-17 idea merely because Stone once installed it.

# STONE 2016-2017 OFFENSE: ONE-PAGE CARD

**Identity:** physical downhill offense + concept-based passing + personnel portability + same-picture conflict.

**System sentence:** Same people can change the picture. The same picture can change the answer.

**Core runs:** Power / Counter-GT / Inside / Outside / Duo. Split is near-core. DART and Jet are weekly tools.

**Core passes:** Stick / Mesh / Drive / Y-Cross / Dagger / Four Verticals. Post-Cross rises in importance.

**Personnel principle:** 11 is the largest grouping, but 12/20/21 must carry enough real football that defensive matching creates new problems instead of solving the offense.

**Back principle:** two or three runners may receive meaningful playing time. Playing time does not require equal carries. 20 TWIN puts two legitimate runners on the field only when their roles create distinct problems.

**Motion principle:** movement now changes fits and leverage, not only coverage identification. JET is a weekly action; ORBIT remains a change-up.

**Conflict principle:** ACCESS is pre-snap. READ is post-snap. One defender, one decision, ball out on time.

**Run principle:** pulling guards and tackles create geometry. GT and DART expand the menu without replacing Power/Counter fundamentals.

**Play-action principle:** do not abandon under center because the league is spreading. The run fake must belong to a run the offense actually calls.

**Tempo principle:** ROTATE to use the roster. HOLD to transform the same people. PRESS when the defensive package is trapped and the call can remain simple.

**6OL principle:** four categories when active: run toward, run away, pass, transform after HOLD.

**Simulation principle:** generate series and answers, not random variety. Repeated success can produce repeated simple calls.

**Play-caller principle:** Show it. Stress it. Punish it. Then show the same thing again with a different answer.
