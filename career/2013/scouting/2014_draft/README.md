# 2014 draft scouting reports

**Opened:** November 17, 2013 (branch date), after Week 11.
**Source directive:** [../2014_draft_focus_directive.md](../2014_draft_focus_directive.md).
**Authority:** Caldwell holds the board and every pick; the scouting department carries volume; coaches review assigned cut-ups in set windows without missing opponent preparation.

## Rules for every report

- **Dated evidence only.** Each entry carries the branch date it was written and the information available on that date: college tape as games are played, then declarations, all-star games, combine, pro days, medicals and interviews on their dated release (pattern: `library/2013_draft_information_gates.md`; a 2014 gates file is still to be built under the two-pass library discipline).
- **No hindsight.** No later NFL result, honour, contract or real draft slot is read or cited.
- **Eligibility is verified, not assumed.** Underclassmen become draftable only on a dated declaration; each prospect's college and status is confirmed against dated sources before it is written here.
- **No numeric grades.** Use the five tiers (Elite / Plus / Average / Below-Average / Replacement-Level) and the directive's questions. A focus-list name gets no grade bonus; an injury on Jacksonville's roster does not inflate a grade.
- **Append, don't rewrite.** A prospect file is a dated log. A new evaluation is a new dated entry; earlier entries stay as written.
- **Research first.** Factual lines (school, eligibility, measurables, college statistics) need a real cited source and a verification pass, or are marked unverified.
