## Resolution and roster cuts

Per Document 7 section 5.1, the preseason resolves as one consolidated bulk turn rather than the weekly loop; the four game folders hold each game's record so the results are easy to find. `final_roster_cuts.md` holds the roster-reduction record (75 by Aug. 27, 4:00 p.m. ET; 53 by Aug. 31, 6:00 p.m. ET). Preseason results never count in the standings.
