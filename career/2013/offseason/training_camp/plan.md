# Jacksonville Jaguars — 2013 Training Camp Plan

**Future event owner when run:** `career/2013/offseason/training_camp/output.md` (create when the verified calendar reaches camp).

**Calendar boundary:** research and verify the actual 2013 Jacksonville training-camp reporting/practice dates, preseason schedule dependencies, roster deadlines, and governing practice/contact rules before execution.

Training camp converts offseason teaching into competitive NFL football.

The question changes from "Can we teach this?" to:

**Can we trust this player and this unit when speed, contact, fatigue, substitution, field position, opponent behavior, and consequences are real?**

Camp is not designed to make players miserable. It is designed to make the roster and system dependable.

## 1. Camp entry standard

Before field competition begins:

1. Verify current roster/control status.
2. Verify medical participation status.
3. Complete onboarding for every late acquisition.
4. Confirm every player has the active 2013 Iteration I playbook and current position material.
5. Deliver the individualized camp-entry expectations created after minicamp or after acquisition.
6. Conduct the medically cleared, position-adjusted camp conditioning test described in the Prowl readiness standard.
7. Record the test standard before players take it and apply it consistently to comparable football jobs.
8. If a player does not meet the entry standard, assign an individualized conditioning/retest plan. Do not use random punishment running.
9. Do not treat a failed conditioning test as an automatic depth-chart verdict.
10. Freeze the opening camp install/practice goals before evaluating players.

## 2. Camp learning architecture

Camp operates through four progressive blocks. The exact dates and number of practices in each block are set only after the real calendar is verified.

### Block 1 — re-establish and acclimate

Purpose:

- re-establish terminology;
- verify offseason retention;
- re-establish individual fundamentals;
- confirm communication;
- rebuild practice tempo safely;
- identify players who need immediate reteaching.

Scheme emphasis:

- core offense;
- base defense;
- core special teams;
- substitution procedure;
- huddle/cadence;
- basic situations.

The staff should not interpret early rust as permanent inability without giving the player the correction/repetition cycle.

### Block 2 — pads, physical execution, and competition

As rules and medical status permit, add the physical component that offseason work could not fully test.

Evaluate:

- leverage;
- block finish/control;
- block defeat;
- contact balance;
- route release;
- pass protection;
- run fits;
- tackling technique and finish under permitted practice structure;
- ball security under pressure;
- physical response to repeated football work.

This is where some spring conclusions should change. The staff should allow them to.

### Block 3 — pressure, variation, and situation

Stress the system with:

- different personnel;
- formation/motion;
- pressure presentation;
- coverage changes;
- third down;
- red zone;
- backed up;
- two minute;
- four minute;
- sudden change;
- end-of-half/game;
- noise/communication;
- substitute entering unexpectedly;
- starter leaving a period;
- special-teams emergency jobs.

The goal is not chaos. The goal is recognizable problems.

### Block 4 — preseason/game operation

Reduce the menu enough to evaluate actual game execution.

Test:

- sideline communication;
- substitutions;
- play-call operation;
- headset/huddle mechanics where applicable;
- clock awareness;
- halftime adjustment;
- game-day special teams;
- backup readiness;
- injury substitution;
- reduced game-plan learning.

Preseason outcomes belong in game/event records, not in this plan.

## 3. Daily camp operating rhythm

The exact hourly schedule is not fixed here. Use the verified league/team calendar and practice rules.

A normal camp day should nevertheless contain the following functions in a sensible order:

- medical/treatment availability;
- position/unit install meeting;
- walkthrough or preview as permitted;
- individual fundamentals;
- group work;
- team work;
- special teams;
- situational period when scheduled;
- immediate hydration/recovery;
- film and correction;
- position-room follow-up;
- treatment/rehab;
- strength maintenance/recovery work as appropriate;
- next-day preparation.

Not every day needs every category at maximum volume.

Hard work is not measured by how little recovery the staff permits.

## 4. Installation rule: mastery before menu size

Training camp opens more of Iteration I, but not indiscriminately.

### CORE

Core concepts should become dependable enough to survive:

- different personnel;
- different fronts/coverages;
- ordinary pressure;
- substitution;
- field zone;
- fatigue.

If a CORE call cannot reach that standard, the staff must identify whether the problem is personnel, teaching, technique, or concept fit.

### WEEKLY

Weekly concepts can be installed and evaluated as game-plan candidates.

A weekly concept earns carry-forward if:

- its teaching burden is justified;
- the roster has players for the jobs;
- it solves a real problem;
- players can execute it without damaging core reliability.

### CHANGE-UP

Change-ups stay small.

A clever call is not valuable if the team needs excessive practice time to run it once.

### Active-iteration lock

Nothing from Stone's 2016-or-later offensive evolution can be imported because it would solve a 2013 problem elegantly. The 2013 team develops only the system Stone has actually reached.

## 5. Offensive camp plan

### Run game

Core priorities:

- Power;
- Counter;
- Inside Zone;
- Outside Zone.

Additional families such as Duo, Split Zone, Pin-Pull, Trap, Wham, Toss/Crack, Jet, Draw, or QB sneak/follow are installed/emphasized only as the roster and weekly purpose justify.

Evaluation questions:

- Are the combinations sound?
- Are backs hitting the intended track?
- Is the perimeter correctly accounted for?
- Does the quarterback understand the run/check responsibility?
- Does the concept still work from multiple presentations?
- Which linemen/backs execute it best together?

### Pass game

Core/major families are developed as concepts, not isolated route drawings.

Evaluate:

- spacing;
- route depth;
- leverage;
- progression timing;
- protection timing;
- checkdown;
- scramble reaction;
- catch/finish;
- ball security;
- whether one position change forces the whole play to be retaught.

### Protection

Pressure periods should teach answers, not merely create sacks in practice.

Quarterback/line/back must agree on:

- point;
- slide/man responsibility;
- weak point;
- hot answer;
- back scan/check;
- adjustment versus overload/mugged presentations;
- when the correct answer is to throw behind pressure or move the launch point rather than add a blocker.

### Personnel packages

The offense should determine which roster combinations genuinely expand the system.

Questions:

- Can 11 run the full core?
- Does 12 create real run/pass multiplicity?
- Does 21/20 improve the roster's best players or just satisfy a diagram?
- Does heavy personnel still threaten pass?
- Which backs/TEs/receivers allow HOLD/PRESS without substitution?

Planning centers in the playbook are not quotas.

### Tempo

NORMAL is the foundation.

ROTATE tests substitutions.

HOLD tests formation/role portability.

PRESS is used with mastered calls and only when the current eleven can operate it.

FREEZE/MILK or other tempo tools are taught as real game operations, not practice theater.

## 6. Quarterback camp competition

Quarterback evaluation is comprehensive.

Track qualitative evidence in:

- command;
- decision;
- protection;
- accuracy/placement;
- timing;
- ball security;
- pocket response;
- movement;
- situational operation;
- two-minute/four-minute command;
- correction retention;
- response after a mistake;
- work with different personnel groups.

Do not create a numeric quarterback rating for internal narrative use unless a sourced real statistic is being recorded from an actual game. This repo's qualitative evaluation language controls.

The quarterback competition should progressively increase first-team/second-team clarity when Stone has enough football evidence to make that decision. Do not pre-award the job in this plan.

## 7. Offensive-line camp competition

Camp is where non-contact assumptions meet physical football.

Evaluate:

- anchor;
- leverage;
- movement;
- combination blocks;
- pass set;
- edge response;
- twist/game communication;
- recovery after losing initial leverage;
- screen/pull movement;
- repeated-effort technique;
- communication across different center/guard/tackle combinations.

Cross-train only when it increases usable depth without destroying primary-position development.

## 8. Skill-position camp competition

### Running backs

Evaluate:

- vision/track discipline;
- burst;
- contact balance;
- ball security;
- pass protection;
- route/screen value;
- motion/flex;
- special teams;
- recovery/workload.

No automatic feature-back quota and no forced equal touch distribution.

### Tight ends / H-backs

Evaluate:

- inline blocking;
- movement blocking;
- protection;
- route separation;
- catch/finish;
- alignment flexibility;
- motion;
- special teams.

### Receivers

Evaluate:

- alignment/splits;
- releases;
- route depth;
- separation;
- catch/finish;
- blocking;
- motion;
- role portability;
- special teams.

A receiver does not earn a job from one explosive catch if assignment/communication remain unreliable. The reverse also holds: one drop does not erase consistently correct work.

## 9. Defensive camp plan

The defense should become difficult to play against because it is sound first, multiple second.

### Run defense

Evaluate:

- gap integrity;
- block defeat;
- edge;
- linebacker fit;
- safety support;
- pursuit;
- tackling;
- communication versus shift/motion.

Do not confuse adding a defender to the box with solving run defense.

### Pass defense

Evaluate:

- rush-lane integrity;
- pressure timing;
- leverage;
- coverage spacing;
- man technique where called;
- match/zone communication where called;
- route distribution;
- explosive-play prevention;
- scramble response.

### Pressure and disguise

Pressure must have a reason.

Camp can expand:

- four-man rush from different presentations;
- five-man pressure;
- overload looks;
- simulated/exchange pressure concepts present in the current defensive system;
- late safety movement;
- disguise.

If the defense busts because it cannot communicate the presentation, simplify it.

## 11. Special-teams camp plan

Training camp makes special-teams competition real.

Each unit develops:

- primary personnel;
- backup personnel;
- emergency replacements;
- substitution procedure;
- communication;
- field-position/situational awareness.

Evaluate:

- assignment;
- speed to landmark;
- leverage;
- block/protection technique;
- tackling/coverage;
- return skill;
- ball security;
- specialist operation;
- willingness to learn multiple jobs.

Special teams can break a roster tie when the football evidence supports it. It is not a token category.

## 12. Situational football menu

Stone's "Practice the Problem" standard receives real camp time.

Rotate situations across camp rather than cramming all of them into one practice:

- third-and-short;
- third-and-medium;
- third-and-long;
- high red zone;
- low red zone;
- goal line;
- backed up;
- coming out;
- plus territory;
- two minute;
- four minute;
- sudden change;
- end of half;
- end of game;
- need field goal;
- protect field-goal range;
- clock running/stopped;
- offense/defense after turnover;
- special-teams transition;
- starter leaves unexpectedly.

The staff should know which calls the team actually trusts in each situation by the end of camp.

## 13. Physical readiness, workload, and recovery

The Prowl requires readiness, not reckless volume.

Performance/medical/coaching staff coordinate within their separate authority.

Track with 2013-appropriate methods:

- manual rep counts;
- practice film;
- timed work where relevant;
- strength-room records;
- body measurements;
- trainer observation;
- position-coach observation;
- player-reported recovery information where voluntarily provided.

Do not silently give the club modern universal GPS/Next Gen workload data.

### Repeated-effort standard

Camp should expose whether technique survives:

- later in a period;
- later in practice;
- after special teams;
- after a long drive;
- during tempo;
- on the next day.

Fatigue is expected. The staff wants to delay technical collapse.

### Injury standard

An injured player is medically limited, not morally deficient.

Evaluate what he can lawfully and medically do. Do not create a negative football character judgment from the diagnosis.

## 14. Competition and depth-chart process

Roles move through football evidence.

Stone controls football roles within medical/eligibility limits. Caldwell retains the personnel/contract/cap authority established elsewhere.

When considering a depth move, distinguish:

- assignment reliability;
- communication;
- technique;
- physical execution;
- consistency;
- situational execution;
- special teams;
- response to correction;
- availability as medically established;
- roster construction implications owned by the GM.

Veteran status does not create lifetime tenure.

Youth does not create an entitlement to replace a veteran.

A move should have a football reason.

## 15. Daily staff evaluation process

After each meaningful practice:

### Position coach

Records:

- what the player was asked to do;
- what was correct;
- correction priority;
- whether prior correction held;
- next teaching step.

### Coordinator

Reviews:

- unit communication;
- concept reliability;
- personnel combinations;
- install burden;
- repeated team-level errors.

### Stone

Focuses on:

- cross-unit issues;
- depth/role evidence;
- practice design;
- whether coaches are teaching consistently;
- whether the current menu is helping or hurting execution.

### Medical/performance

Communicate only their proper football-relevant status/recommendations.

Private medical detail stays private.

## 16. Good, Better, Best in camp

**Good**
- player knows the job;
- communicates;
- executes base technique;
- can function in the practice.

**Better**
- correction holds;
- technique survives changing pictures and repeated work;
- player needs less rescue;
- situational awareness grows.

**Best for current camp**
- player executes fast and reliably;
- can handle adjacent responsibilities;
- stabilizes teammates;
- survives physical/situational variation;
- self-corrects routine issues.

These are phase descriptions, not permanent numeric ratings.

## 17. Family program during training camp

Because training camp is longer and more demanding than the earlier phases, schedule family inclusion more than once when the verified calendar/logistics permit.

### Camp Opening Family Dinner

Held early in camp.

Invite all current players, coaches, appropriate staff, and invited family/meaningful guests.

Purpose:

- welcome families into the camp period;
- introduce support contacts;
- establish practical communication channels;
- create normal human familiarity across the organization.

No depth-chart speech or football meeting.

### Mid-Camp Family Night / Dinner

Schedule on an appropriate recovery/short-work window when permitted.

Purpose:

- reconnect players with family during the most demanding stretch;
- let families spend time together;
- allow Player Development to make support available;
- give coaches/staff families a place in the team community too.

Rules for both events:

- family/guest attendance is voluntary;
- no private family circumstance becomes personnel information;
- no attendance grade;
- no financial/medical/counseling discussion is solicited publicly;
- children/partners/parents/other meaningful guests are welcomed without requiring one definition of "family";
- the club handles event logistics as an organizational function, not as a player obligation disguised as culture.

Actual dinners are logged in training-camp output when they occur.

## 18. Preseason integration

Preseason games are not separate from camp evaluation.

Before each game:

- reduce to an executable menu;
- define the players/units being evaluated;
- identify special-teams opportunities;
- set game-management/situational objectives;
- do not pre-write outcomes.

After each game:

- grade assignment/technique/context qualitatively;
- identify corrections;
- adjust competition reps when warranted;
- update medical status only from medical authority;
- keep future-real-life knowledge out.

## 19. Roster-decision preparation

As roster deadlines approach, staff recommendations should be built from accumulated evidence, not the most recent practice alone.

For each competition, summarize:

- football role;
- core reliability;
- upside of expanded role based only on current evidence;
- special-teams value;
- position flexibility;
- medical availability/status as properly communicated;
- consistency;
- unresolved question.

Stone provides football recommendations.

Caldwell makes personnel/contract decisions under the established authority map.

Do not backfill a later career outcome as justification.

## 20. Camp closeout

By the end of camp/preseason preparation, Jacksonville should have:

- a dependable core offensive menu;
- a dependable base defensive menu;
- trusted special-teams operations;
- clear communication;
- role/depth decisions supported by current football evidence;
- known backup/emergency responsibilities;
- unresolved questions identified honestly;
- individualized continuing development priorities.

The goal is not to have installed the most football.

The goal is to enter the season able to execute the football Jacksonville chose to carry.
