# Financial supporting records

[Career finances](../README.md)

Every player contract, future schedule, departed-player charge, draft asset and club-level accounting figure is stored once, with the basis and source of each adopted amount. The [cap tracker](../salary_cap/cap_tracker.md), the [contract details](../player_contracts/contract_details.md), the [player decisions](../upcoming_decisions/player_decisions.md), the [future commitments](../future_commitments/commitments.md) and the [dead-money page](../history/dead_money.md) are all built from those terms, never edited by hand.

After an actual financial event, the event record, the affected current views and every remaining year of the stored terms change together. A superseded agreement is replaced rather than kept as a second copy. Scheduled cash, paid cash, remaining guarantees and cap charges are different figures, and completed-year history is kept when the horizon advances.
