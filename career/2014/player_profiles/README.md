# 2014 annual player profiles

**Checkpoint:** March 28, 2014 working profile  
**Current controlled players:** 55

Every currently controlled player has a 2014 annual sheet. Returning players
inherit their 2013 established state by default. New acquisitions keep
permitted pre-Jacksonville football capability while Jacksonville system
knowledge and teammate timing begin as new context.

Visible /10 grades and NFL standing remain unassessed until the existing
evidence is deliberately translated into the annual-sheet scale. The files do
not invent a league rank simply to fill the template.
