## Camp integration and execution

Use the complete [preseason output template](../../../../foundation/templates/preseason_output_template.md) for each played game's report and for the bulk chat output. Preserve its eight sections. Section 4 places the full Report to render directly beneath each game narrative; the [consolidated review guide](../../../../foundation/templates/training_camp_and_preseason/preseason_review.md) supplies section 6's cross-game assessment. The reports connect camp questions to actual game execution, useful player comparisons and the next correction. Keep the score and full generated box score, with all technical claims supported by the game record. No game has been played merely because its report format exists.

Each report combines the game story with a review of how the offense, defense and special teams played, whether their communication worked, and what named players did well or poorly. Follow the actual starters, reserves and mixed combinations. Relate the findings to taught assignments, support and opposition, then identify the coaches' next work. The [research and worked example](../../../../docs/preseason_game_reports.md) explain the expected depth; their historical examples supply no 2014 game facts.

The [camp plan](../Training_Camp/staff_plan.md), [output](../Training_Camp/training_report.md), [position review](../Training_Camp/training_report.md#personnel-questions-after-august-4) and [decisions](../Roster_Decisions/roster_decisions.md) supply the whole body of evidence. Follow Document 7's consolidated preseason process, preserving each game's own output. Afterward preserve the appropriate receipt, link actual player evidence and distribution, reconcile medical/role/transaction changes and update the calendar/current checkpoint. Preseason statistics never enter regular-season standings or the regular-season statbook.
