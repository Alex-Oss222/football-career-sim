# Head-coach changes, 2014

Every club's head coach, Jacksonville's included, is checked in the same way after each of the club's regular-season games: from the club's record after the game and whether the coach is in his first season with the club. A club that changes its head coach is not checked again that season, and the change takes effect the day after the club's game.

## Changes

No club has changed its head coach this season.
