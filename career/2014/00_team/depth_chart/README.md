# Depth chart

[Team](../README.md)

The working order carries between seasons. A practice starting point remains open to competition until Stone makes a later decision.

| Open | What you will find |
|---|---|
| [Read the depth chart](depth_chart.md) | Position order, special teams, rep starting points, competitors and dated changes. |
| [Working depth data](working_depth_chart.json) | The same working assignments used during preparation. This is not a released game-day roster. |

When the season’s game inputs are released, `game_depth_chart.json` holds the verified game roster. That file is not created by a folder reorganization.
