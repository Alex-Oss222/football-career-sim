## Running a week after release

Read the current checkpoint and calendar, frozen fixtures, actual roster/medical instructions, installed playbooks and existing ex-ante plan. Pass both repository and game readiness, including season-aware inputs and weekly control exclusivity. Follow the existing one-command weekly workflow for Jacksonville and all background games through the same kernel. No hidden protagonist bonus, branch-win talent rating or real result may enter resolution.

A game week needs the pre-result plan/call sheet, permitted training, actual game output, full Jacksonville public receipt, background compact-stat receipts, generated season stat/standings views, actual individual feedback/film receipts and atomic event closure. Each week's `output.md` follows the [weekly game turn template](../../../../foundation/templates/season_output_template.md): header and coach record (`scripts/render_coach_record.py`), week setup, pregame Q&A, the game by quarter, the generated full stats block (`scripts/render_box_score.py --season 2014 --write`, gamebook layout: scoring summary, team stats, individual tables, drive chart, snap counts), postgame Q&A, takeaways, personnel snapshot and closure. The [individual workflow](../../offseason_training/coaching_methods/weekly_workflow.md), [player profiles](../../team/player_development/roster_profiles.md) and [staff evolution](../../early_offseason/staff_changes/README.md) continue throughout the season.

On the actual bye, use the permitted review/time-off process; no Jacksonville game or fake game receipt is created. Background games still close normally. Preserve experience and supported player strengths while revising open questions from actual work. Do not backdate tapes or interpret a generated season total as mastery.

After the final regular-season week, qualification and reseeding come only from branch receipts. The [calendar's conditional postseason dates](../../calendar.md#year-end-and-conditional-2015-postseason-handoff) govern January–February 2015. No playoff berth, opponent or season-close date is assumed.
