# Jacksonville medical records

[Current participation report](current_injury_report.md) · [Dated medical history](medical_history.md)

The medical history owns communicated examinations, restrictions and clearances. A documented new injury receives its own dated incident record using the [medical report template](../../../../foundation/templates/medical_injury_report_template.md); subsequent updates stay with that incident. No injury dossiers are created without an actual incident. The [roster](../Team/Roster/roster.md) remains the current player-control record, and the depth chart owns coaching deployment.
