# Depth chart

[Team](../README.md)

Stone's season game depth chart was issued August 30, 2014 at the reduction to 53 and is the released 2014 game input; the working copy mirrors it with contract flags, availability notes and the update log. A chart place is Stone's decision, changed only by decision and logged.

| Open | What you will find |
|---|---|
| [Read the depth chart](depth_chart.md) | Position order, special teams, rep starting points, competitors and dated changes. |
| [Game depth chart](game_depth_chart.json) | The released 2014 game input: depth by kernel group, positions, roles, the captains and the Week 1 inactives. |
| [Working depth data](working_depth_chart.json) | The same chart with contract flags, availability notes, the removed-player history and the update log. |

`game_depth_chart.json` holds the verified game roster from August 30, 2014; change it, the working copy and the readable log in the same commit.
