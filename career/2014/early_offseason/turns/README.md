# 2014 offseason turn outputs

One narrative output per offseason turn, from the end of the 2013 season to the day before the 2014 preseason report. Each follows the [offseason output template](../../../../foundation/templates/offseason_output_template.md) and is written from the closed ledger entries for its dates; it records no event of its own.

Files are named `YYYY-MM-DD_to_YYYY-MM-DD.md` after the turn's first and last dates.
