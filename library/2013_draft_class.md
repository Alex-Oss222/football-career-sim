# Library: 2013 NFL Draft Class (Pre-Selection Data Only)

**Status:** Research pass completed and independently verified 2026-09-17. Strictly pre-selection information only — measurables, combine testing, college production, and pre-draft consensus rankings. **No player's post-draft career outcome (statistics, awards, bust/star framing, anything after he was actually selected) is recorded here or anywhere else in this project**, per Document 2 §12's quarantine rule: real post-selection outcomes must never leak into evaluation, even indirectly.

**How this is used per Document 2 §12:** the real 2013 class (below) is the confirmed prospect pool through this documented year. The real draft ORDER below is a comparator/reference only — the simulation's own draft order is computed fresh from its own standings and will diverge from the real order the moment any simulated team's season differs from history, which becomes likely as soon as the protagonist's presence changes any team's fortunes. Do not copy the table below into Document 2 §12's live pick-inventory table as if it were the simulation's order.
