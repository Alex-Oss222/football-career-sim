# Preseason games: per-game sequence

The uploaded four-game checklist is folded into the [preseason games design](../../../docs/preseason_games.md#per-game-sequence), section E, "Per-game sequence": one row per game in the season's fixtures, with the freeze and closure checklists for each game. The build merges those steps into the [season cycle milestones](../../../docs/season_cycle_milestones.md) and a preseason section of the [run sequence](../../../docs/run_week.md); it is not a separate checklist page.
