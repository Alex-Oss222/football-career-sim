# Preseason game report template

Use the [report instructions](README.md). This is the preseason version of the [season output template](../season_output_template.md); its evidence, narrative, media and generated-box-score rules still apply. The game must have been resolved through the authorized game process. An unplayed game gets a preparation note, never a filled result or simulated highlight added by the report writer.

## Report to render

# [Team] | Preseason game [number] | [Opponent, date and venue]

**Final:** [Verified result from the game receipt.]

## What the staff wanted to see

[Briefly identify the actual camp questions, installed game menu, planned personnel opportunities and material workload limits. Distinguish what was planned from who actually played. Do not assume every starter plays the same number of series or that game three always has a fixed rehearsal role. Include the recorded pregame media exchange when there is one.]

## How the game unfolded

[Write a selected game story from the generated evidence. Explain the sequences that changed the game or materially answered an evaluation question. Include offense, defense and special teams where each affected it. Preserve the result without treating the score as the sole assessment. Name opponent personnel or technical causes only when the record supplies them. A reserve's production against a different group needs that context, not an automatic downgrade or promotion.]

## Box score

[Insert the complete generated box score for both teams using the repository's supported preseason receipt/rendering path. Preserve the game's receipt and provenance. Do not hand-fill a number or route the preseason game through a regular-season statbook just to populate this section. If the production path cannot provide the required record, report the specific blocker.]

## What the game showed about the players

[Use the player-assessment method for the material findings. Connect the game to the earlier camp question. Did a protection correction survive a live rush? Could the tight end block the assigned defender and still supply the route threat? Did the defense keep its help and contain when the opponent changed the look? Ask only questions supported by the actual calls. Explain an inconclusive sample plainly. Statistics and isolated highlights do not establish assignment quality.]

## Stone's decisions and the next practice

[Record the consequential choices Stone actually made and their effects. Separate the call from its execution. Give each material correction a coach and next opportunity; do not invent the follow-up result. State actual role or availability changes and link their owners. Include recorded postgame media in Stone's established voice, without manufacturing quotes while retrospectively rewriting a game. Close with the next work, or the genuine choice that pauses the bulk preseason turn.]
